## 🎯 What is BlockPilot?

BlockPilot transforms smart contract security from a weeks-long, expensive process into instant, AI-powered analysis. Built exclusively for 0G Network, it combines Mistral AI's advanced language models with 0G's decentralized storage and compute infrastructure to deliver enterprise-grade security audits in under 30 seconds.

**The Problem:** Developers deploy vulnerable contracts because traditional audits are slow and costly.

**Our Solution:** Real-time AI security analysis with decentralized report storage and on-chain verification.

## ✨ Core Features

### 🧠 **AI Security Auditor**
- Instant vulnerability detection powered by Mistral AI (mistral-large-latest)
- Severity classification: Critical, High, Medium, Low
- Gas optimization recommendations
- 5-star security rating system
- Professional PDF reports with on-chain verification

### 🏗️ **Smart Contract Builder**
- Production-ready ERC20 and NFT templates
- Zero-dependency, security-first design
- Auto-audit on deployment
- One-click deployment to 0G Galileo Testnet
- Real-time transaction monitoring

- Audit reports stored on 0G Storage with Merkle root verification

- Cryptographic integrity verification

- AI-powered contract documentation
- Context-aware generation (purpose, audience, technical level)

- Tailored explanations from beginner to advanced

### 🧪 **Test Case Generator**
- Multi-framework support: Hardhat, Foundry, Remix
- Comprehensive test coverage for all functions
- AI-generated test suites with best practices
- Copy-ready code for immediate use

### 🎨 **Modern UI/UX**
- Light/Dark theme with unique hanging bulb toggle
- Responsive design for all devices
- Smooth animations with Framer Motion
- Accessible, WCAG-compliant components

## 🚀 Quick Start

```bash
# Clone and install
git clone https://github.com/yourusername/BlockPilot.git
cd BlockPilot
npm install

# Configure environment
echo "MISTRAL_API_KEY=your_key" > .env.local

# Run development server
npm run dev -- --webpack
```

**Prerequisites:**
- MetaMask with 0G Galileo Testnet configured
- 0G testnet tokens from [faucet.0g.ai](https://faucet.0g.ai)
- Mistral AI API key

**Try it live:** [blockpilot.netlify.app](https://blockpilot.netlify.app/)
