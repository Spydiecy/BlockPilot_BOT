## ⚡ Get Started in 60 Seconds

### **Prerequisites:**
```bash
✅ MetaMask or Web3 wallet
✅ 0G Galileo Testnet configured (Chain ID: 16602)
✅ 0G testnet tokens (get from https://faucet.0g.ai)
✅ Mistral AI API key (for AI analysis)
```

### **Quick Start:**
1. **Clone & Install**
   ```bash
   git clone https://github.com/yourusername/BlockPilot.git
   cd BlockPilot
   npm install
   ```

2. **Configure Environment**
   ```bash
   # Create .env.local file
   MISTRAL_API_KEY=your_mistral_api_key
   OG_RPC_URL=https://evmrpc-testnet.0g.ai
   OG_PRIVATE_KEY=your_private_key_for_backend_operations
   ```

3. **Run Development Server**
   ```bash
   npm run dev -- --webpack
   # Visit http://localhost:3000
   ```

4. **Connect Wallet**
   - Click "Connect Wallet" in the navbar
   - Approve MetaMask connection
   - Switch to 0G Galileo Testnet if prompted

5. **Build & Deploy Contracts**
   - Go to Contract Builder
   - Choose ERC20 or NFT template
   - Customize parameters
   - Enable "Audit on Deploy" for automatic security analysis
   - Click "Deploy Contract"

6. **Audit Existing Contracts**
   - Go to Audit page
   - Paste your Solidity code
   - Click "Analyze Contract"
   - View detailed security report
   - Download PDF for documentation

### **Network Configuration:**
```javascript
Network Name: 0G Galileo Testnet
RPC URL: https://evmrpc-testnet.0g.ai
Chain ID: 16602 (0x40BA)
Currency Symbol: 0G
Block Explorer: https://chainscan-galileo.0g.ai
```

## 🎯 **API Routes**

### **AI Analysis**
```typescript
POST /api/ai/analyze
{
  "contractCode": "pragma solidity ^0.8.19; ..."
}

Response:
{
  "analysis": {
    "summary": "Security analysis summary",
    "stars": 4,
    "vulnerabilities": {
      "critical": [],
      "high": [],
      "medium": [],
      "low": []
    },
    "gasOptimizations": [],
    "recommendations": []
  }
}
```

### **0G Storage**
```typescript
// Upload
POST /api/0g-storage/upload
{
  "content": "{ report JSON }",
  "metadata": { "type": "audit-report" }
}

// Download
POST /api/0g-storage/download
{
  "reportHash": "0x..."
}
```

### **Contract Compilation**
```typescript
POST /api/compile-contract
{
  "sourceCode": "pragma solidity ^0.8.19; ..."
}

Response:

  "abi": [...],
  "bytecode": "0x..."
}
```
